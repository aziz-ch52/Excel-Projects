# 📂 Projects Included

## 🛒 Supermarket Sales Dashboard

An interactive Excel dashboard built using 1,000+ supermarket transaction records to analyze:

- Revenue trends
- Product performance
- Customer behavior
- Payment methods
- Regional sales analysis

### 🔹 Features
- Dynamic KPI Cards
- Connected Pivot Tables
- Universally Wired Slicers
- Interactive Charts
- GETPIVOTDATA Modeling
- Dashboard UI/UX Design

### 🔹 Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Power Query
- GETPIVOTDATA
- Data Visualization Techniques

### 🔹 Key Business Insight
By dynamically segmenting the dataset, the dashboard identified:

> Female shoppers in the Yangon branch showed strong purchasing behavior in the Food & Beverages category, with significant usage of E-wallet payment methods.
