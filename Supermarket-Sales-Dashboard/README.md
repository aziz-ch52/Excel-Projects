# 🛒 Supermarket Sales Dashboard

An interactive Excel-based Business Intelligence dashboard built to analyze 1,000+ supermarket transactions and transform raw retail data into actionable business insights using advanced Excel analytics techniques.

---

# 📌 Project Overview

This project focuses on building a dynamic and interactive sales analytics dashboard in Microsoft Excel using:

- Pivot Tables
- Pivot Charts
- Slicers
- GETPIVOTDATA
- KPI Cards
- Data Modeling
- Dashboard UI/UX Principles

The dashboard enables business users to dynamically filter and analyze sales performance across:

- Cities
- Branches
- Customer Types
- Gender
- Time Periods

---

# 🎯 Business Objective

The goal of this project was to simulate a real-world retail analytics environment where executives can:

- Monitor revenue performance
- Analyze customer behavior
- Compare payment methods
- Track monthly sales trends
- Identify top-performing product categories
- Generate business recommendations from data

---

# 📊 Dashboard Features

## ✅ Dynamic KPI Cards
- Total Revenue
- Total Transactions
- Average Rating
- Top Product Category

All KPIs are dynamically linked using `GETPIVOTDATA()` and respond instantly to slicer selections.

---

## ✅ Interactive Slicers
Implemented universally connected slicers for:

- City
- Branch
- Gender
- Customer Type
- Month

All slicers are fully synchronized across every Pivot Table and chart.

---

## ✅ Visual Analytics
### Included Charts:
- Product Line Revenue (Horizontal Bar Chart)
- Monthly Revenue Trend (Line Chart)
- Payment Method Share (Donut Chart)

---

# 🧠 Key Business Insight

Using dashboard segmentation, I discovered:

> For female shoppers in the Yangon branch, the highest-performing product line was **Food & Beverages**, while a significant percentage of customers preferred **E-wallet payments**.

This demonstrates how interactive filtering can uncover customer purchasing behavior and regional trends.
